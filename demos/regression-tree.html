How does a regression tree split the data?

Click to add points. Drag the depth slider and watch the tree carve the data into boxes, one split at a time.

For a startup working on concrete with lower emissions, I made an optimisation engine that suggests concrete recipes. To model how a recipe behaves, I used regression trees. A tree is a sequence of yes/no questions, which made it possible for people to see why a recipe was suggested.

How a tree is grown

A regression tree splits the input space into boxes \(R_1, \dots, R_J\) and predicts a constant in each of them, which is the average of the training points in that box:

$$\begin{gathered}\hat f(x) = \sum_{j=1}^{J} c_j\,\mathbf 1[x \in R_j], \\ c_j = \frac{1}{|R_j|}\sum_{x_i \in R_j} y_i.\end{gathered}$$

Finding the best boxes overall is not feasible, so trees are grown greedily. At each node we try every feature \(j\) and every threshold \(s\), split into \(R_L = \{x_j \le s\}\) and \(R_R = \{x_j \gt s\}\), and keep the split that reduces the squared error the most:

$$\min_{j,\,s}\Big[\sum_{x_i\in R_L}(y_i - \bar y_L)^2 + \sum_{x_i\in R_R}(y_i - \bar y_R)^2\Big].$$

This is repeated on each side until a stopping rule is reached, such as a maximum depth, a minimum number of points in each leaf, or no split that reduces the error enough.

When you drag the dashed line, each side predicts its own average, and the total squared error changes with the threshold. The tree chooses the threshold at the minimum of the error curve.

Depth

A tree with depth \(D\) has at most \(2^D\) leaves. A shallow tree is easy to read but misses structure in the data (high bias), and a deep tree can fit almost anything, also the noise (high variance). In practice the depth is chosen with cross-validation, or a deep tree is pruned by penalising the number of leaves \(|T|\):

$$C_\alpha(T) = \sum_{j=1}^{|T|}\sum_{x_i\in R_j}(y_i - c_j)^2 + \alpha\,|T|.$$

Try it yourself

Why trees

A shallow tree can be read as a set of rules, for example that a certain cement content and replacement share gives a certain strength. This made it easier for engineers, who know concrete much better than any model, to trust the suggestions. Trees also handle thresholds and interactions between the inputs without extra work, which suits material properties that can change abruptly. Finally, a tree is cheap to evaluate, so a genetic algorithm can call it thousands of times. The optimisation is the other half of the project, and it is described in the note about cheap and green concrete.

The same greedy splitting is used in random forests, which average many trees fitted to bootstrapped data, and in gradient boosting, where trees are fitted one after another to the remaining errors.
